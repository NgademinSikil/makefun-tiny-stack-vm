# makefun-tiny-stack-vm

A tiny stack VM for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122?ref=ds1567x3)'s "Build a tiny stack virtual machine, 22 November 2026" bounty.

`main.ts` is the whole entry: one interpreter for the kit's 32-bit stack ISA
(256-value stack, calls, 256 words of memory, all ten traps, step and output
limits). Practice set: **1,000,000 of 1,000,000** — all 40 instances match
the reference VM byte for byte.
